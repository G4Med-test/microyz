# Portal JSON parser

Rewritten from `geant-config-generator/tests/geant4/microyz/parser.py` (old
`gts.BaseParser`, which **shelled out to `root -l -b -q microyz_plot.C(...)`**
to post-process the raw `yz.root` ntuple into `result.txt`, then merged
repeated-seed/multi-energy job groups into one curve) for the module-level
`metadata()`/`parse()` API that `ci-workflows/validation/export.py` actually
calls. There is no ROOT binary (interactive or batch) or PyROOT available on
the CI runner, so `microyz_plot.C`'s computation — the population-weighted
mean lineal energy `yF = Σ(nbHits/nbScoredHits · y) / Σ(nbHits/nbScoredHits)`
over the `"yz"` `TNtuple`'s entries — is reproduced directly in Python with
`uproot` reading the ntuple's `nbHits`/`nbScoredHits`/`y` branches, instead
of invoking ROOT as a subprocess.

`geant-validation-tests/src/microyz` only shipped `init_vis.mac`/`vis.mac`
(interactive visualization, not self-contained — `init_vis.mac` itself does
`/control/execute vis.mac`) — no validation macro existed to import as-is.
`config.json` selects 4 macros generated by substituting
`geant-config-generator/tests/geant4/microyz/template.conf` with the
`dna_opt2` physics list across 4 representative beam energies (0.1, 1, 5,
10 keV) out of `params.conf`'s full 20-value sweep and 7 physics lists —
generate more macros the same way if needed. The two optional
`/process/inactivate e-_G4DNAVibExcitation`/`e-_G4DNAAttachment` lines were
dropped: `params.conf` leaves their substitution value blank or `---` for
every row, which doesn't resolve to a valid UI command argument, and
they're not needed for the core y/z microdosimetry calculation.

Because there's no job-group merge any more (one macro means one run), each
macro now yields its own **single-point** chart (`nPoints: 1`) instead of
the original's one chart with the full energy sweep — the same restructuring
applied to `fanoCavity`'s `ROVER` sweep in this organization; the portal is
expected to combine same-`testName`/`title`/`model` records across the
separate `plots/*.json` files into one displayed curve.
